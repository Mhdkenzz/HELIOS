# Helios Documentation

Welcome to the Helios documentation. Helios is a lightweight watchdog and replay tool designed for AI coding agents.

## Quick Start

```bash
pipx install helios
cd ~/my-project
helios run -- your-agent-command --arg value
# Dashboard available at http://localhost:6767
```
